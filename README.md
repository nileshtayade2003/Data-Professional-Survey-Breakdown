# Data Professional Survey Breakdown

## 📊 Project Overview

This project analyzes survey data from data professionals to uncover insights into demographics, job roles, salaries, and industry trends. The analysis is visualized through an interactive Power BI dashboard.

---

## 📂 Dataset

- **File**: `data professional survey.xlsx`
- **Source**: Survey conducted by Alex The Analyst in September 2022.
- **Contents**: Information on respondents' demographics, job roles, salaries, work-life balance, and more.

---

## 🛠️ Tools Used

- **Power BI**: For data cleaning, analysis, and visualization.

---

## 🔍 Analysis Process

1. **Data Connection**: Imported the dataset into Power BI Desktop.
2. **Data Cleaning**: Utilized Power Query Editor to:
   - Remove duplicates and irrelevant entries.
   - Handle missing values appropriately.
   - Standardize categorical variables.
3. **Data Modeling**: Established relationships between tables and created necessary calculated columns/measures.
4. **Visualization**: Developed an interactive dashboard to represent key insights.

---

## 📈 Key Insights

- **Demographics**:
  - Majority of respondents are from the United States.
  - Average age of professionals is approximately 30 years.

- **Salaries**:
  - Data Scientists have the highest average salaries, followed by Data Engineers and Data Architects.
  - Notably, female data professionals earn, on average, 2% more than their male counterparts.

- **Career Transitions**:
  - 59% of respondents have switched their careers to the data domain.
  - 42% found the transition neither easy nor difficult, while 25% found it challenging.

- **Programming Languages**:
  - Python is the most popular programming language among data professionals, especially among Data Analysts.

- **Job Satisfaction**:
  - Average rating for work-life balance satisfaction is 5.74 out of 10.
  - Average rating for compensation satisfaction is 4.27 out of 10.
  - 4 out of 10 professionals are not satisfied with their salary.
